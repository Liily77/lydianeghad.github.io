# Databricks Project: Scala and PySpark Analysis 🚀

👉 [View the project here](https://lydianeghad.alwaysdata.net/databricks/index.html)

## Description 🖋️

This project was carried out on **Databricks**, using Scala and PySpark to analyze complex datasets and perform advanced calculations. The main objective was to manipulate, transform, and visualize data while adhering to the provided instructions.

## Main Objectives ✔️

1. Loading and processing JSON data.
2. Creating data cubes for multi-dimensional analysis.
3. Performing cross-analyses between students and professors.
4. Implementing a system for prioritizing and organizing results.
5. Generating visualizations and logically sorting results.

## Technologies Used 💻

- **Databricks**: A collaborative platform for large-scale data analysis.
- **Scala** and **PySpark**: Languages used for data manipulation and analysis.
- **SQL**: For queries and cross-analysis.
- **JSON**: Format of source data.

## Overview of Analyses Conducted 📊

1. **Calculation of multidimensional cubes**:

   - Analysis of student data and scholarships.
   - Organization of results by universities and years with prioritization (`All_Years`, `All_Univ`).

2. **Cross-analysis of students and professors**:

   - Associating professors based on their courses.
   - Handling cases where no professor is associated (`Profs_No_Recompensés`).

3. **Logical sorting of results**:

   - Custom ordering for enhanced readability.
   - Clear and structured visualization of data.
