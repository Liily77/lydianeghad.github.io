# Project: HTML/CSS Tutorial Website 🖥️🎨

👉 View the website here: [Tutorial Website](https://lydianeghad.alwaysdata.net/duweb24/CSS/TP3/Template.html)

## Description 🖋️

This project is an interactive tutorial created with HTML and CSS, designed to teach the basics of front-end development through a clear and intuitive interface. I've fully designed the site, including a custom logo created on Canva, along with an associated brand name to give the project a distinct visual identity.

## Project Structure 💡
The website is structured into several sections:

- **Header and Navigation Bar:** Implemented using semantic tags such as `header`, `nav`, and `ul`, facilitating easy navigation between different tutorial sections.
- **Main Content:** Organized logically using semantic tags such as `section` and `article`, enhancing the learning experience of HTML and CSS.
- **Footer:** Contains additional information and links to other useful resources.

## Technologies Used 💻

- **HTML5:** For structuring the site with modern semantic tags, ensuring content accessibility and clear organization.
- **CSS3:** For styling the site with responsive layouts (adaptable to various screen sizes), animations, and visual effects.
- **Canva:** Used creatively and professionally to design the website's logo.
