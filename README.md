### **🔹 Project: Power BI & Azure – Analysis of Meublatex Company 🛋️📊**

👉 [View the project here](https://github.com/Liily77/lydianeghad.github.io/tree/Projet_PowerBI_Azure)

**Description:**  
In this project, we implemented a decision-support system for a fictional furniture retail company (**Meublatex**), combining **Data Engineering** and **Data Analytics** skills.

The project consists of two main phases: data ingestion and transformation using **Azure Data Factory**, followed by visualization and analysis with **Power BI**.

**Phase 1 – Data Engineering:**  

◾ Storage of source files (sales, customers, stores, products, expenses) in an **Azure Data Lake**.  
◾ Creation of an **ODS** for raw data.  
◾ Populating a cleaned **Data Warehouse** using **Azure Data Factory**.  
◾ Construction of **Master Pipelines**:  

&nbsp;&nbsp;&nbsp;&nbsp;• `Master_Pipeline_ODS`  
&nbsp;&nbsp;&nbsp;&nbsp;• `Master_Pipeline_DWH`  
&nbsp;&nbsp;&nbsp;&nbsp;• `Master_Pipeline` (global)  

**Phase 2 – Data Analytics:** 

◾ Creation of an interactive **Power BI report** with several pages:  

- **Home**: store locations, overall revenue, time-series analysis  
- **Product Analysis**: top-selling products, profit margin  
- **Customer Analysis**: most profitable customers  
- **Expense Analysis**: breakdown by category  
- **Profit Analysis**: revenue vs expenses
  
◾ Utilization of **DAX** to build **dynamic KPIs**.  
◾ Interactive filters, slicers, and advanced segmentation for exploration by period, store, product, etc.

**🛠️ Technologies:**  
Azure Data Factory, Azure Data Lake, Power BI, SQL, DAX, Git
